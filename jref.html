JRef

A local, file-first reference manager for people who write papers in LaTeX. Every PDF is stored once, named after its citation key, and every project keeps its own BibTeX file up to date, if you like directly inside the folder of the manuscript you are writing.

Main capabilities

  • Import by drag and drop

    PDFs are hashed (SHA-256) so duplicates are refused. JRef reads the DOI or arXiv ID from the first pages, fetches the record from Crossref or arXiv, and falls back to an OpenAlex title search when the PDF prints no identifier.

  • Deterministic keys and file names

    Surname_Year, Surname1_Surname2_Year, Surname1_et_al_Year, with a, b, … on collisions. The same string is the BibTeX key and the file name: pdfs/<year>/<key>.pdf.

  • Projects as logical collections

    One PDF can belong to any number of projects without being copied. Each project writes its own .bib, optionally with a second copy next to your .tex, and protects acronyms and proper names in titles with braces.

  • Manuscript check

    Compares the keys cited in your .tex files with the project: cited but missing (one click adds those the library has), and never cited.

  • Full-text search

    Over metadata and the text of the PDFs (SQLite FTS5), with field syntax such as author:anand journal:solids year:2015-2020 is:unread. Ctrl+K also runs commands.

  • Several devices, one library

    PCs and an Android app share one library through any synchronised folder (Dropbox, Google Drive, OneDrive, Qsync, Syncthing) using per-device change journals instead of a shared database.

  • Share a project

    Export a project as a ZIP with its PDFs named after their citation keys plus the .bib, ready to send to colleagues. The library itself is not touched.

  • Study mode and Ask AI

    Notes and questions about a paper, using your own API key (OpenAI, Anthropic, Google) or a local model through Ollama.

  • Inbox, supplements, Mendeley

    An inbox folder imports whatever you save into it, entries can carry supplementary files and notes, and a Mendeley import leaves your PDFs where they are.

Getting started

On Windows, run the installer: it installs for the current user, needs no administrator rights and brings its own Python. On Windows, macOS and Linux you can also run it from source (Python 3.11 or later): 

git clone https://github.com/jciambella/JRef jref
cd jref
python -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[gui]"
jref

The desktop app is built with PySide6 and the Android app with Kivy. Setup, sync and AI documentation are in the repository.
